# 기능 현황

발표에서 말해도 되는 것과 말하면 안 되는 것을 가르는 표입니다.
✅ 는 실제로 동작하고, 🎬 는 시연을 위해 흉내 낸 것이며, ❌ 는 없는 기능입니다.
🎬 와 ❌ 를 "된다"고 말하지 마세요.

## 두 개의 시연 트랙

두 시연은 **서로 다른 사람의 서로 다른 상황**입니다. 언어 전환은 번역일 뿐,
같은 사람이 두 문서를 다루는 것이 아닙니다.

| | 트랙 1 | 트랙 2 |
|---|---|---|
| 사용자 | 한국 고령자 | 일본 고령자 |
| 문서 | 지방세 납세고지서 (별지 제8호서식 구조) | 가스요금 払込票 → 결제앱 화면 |
| 어려운 지점 | 납기 내/후 두 날짜·두 금액, 전자납부번호와 계좌번호 혼동, 가산세 계산식 | 바코드 결제 개념, 앱 잔액과 통장 잔액의 차이, 「지금 내기」와 「예약」, 이중 납부 |
| 설명하지 않는 것 | "86,400원이 금액입니다" | "8,181엔이 금액입니다" |

숫자를 읽어 주는 것은 도움이 아닙니다. 두 트랙 모두 **당사자가 실제로 막히는
지점**만 설명합니다.

## ✅ 동작하는 것

| 기능 | 확인 방법 |
|---|---|
| 예시 문서 3종 분석 (지방세 / 가스요금 / 결제앱 화면) | `/capture` 에서 고르면 즉시 |
| 선택지 3개로 시작 (네/아니요 아님) | `/confirm` — 문서에 따라 선택지가 달라짐 |
| 낼 수 있는 방법 목록 | 문서에 적힌 수단만. 근거 없는 수단은 서버가 지움 |
| Evidence Lens (원문 위치 하이라이트) | 종이와 폰 화면 모두. 좌표는 문서 데이터에서 계산 |
| 단계별 함께 해결 6단계 | `/solve` |
| 문서 종류별 매뉴얼 | `/tutorial` — 개인정보·실제 금액 없음 |
| 연습본으로 복습 (고정 3단계 힌트) | `/practice` — 실제 문서와 다른 값 |
| 도움 수준 자동 감소 | 따라 하기 → 힌트 연습 → 혼자 → 마지막 확인 |
| 한국어 / 일본어 전환 | 상단 🌐 버튼. 결과는 그 언어로 다시 분석 |
| 글자 크기 3단계 순환 | 상단 가 버튼. 마지막에서 다시 작아짐 |
| 한국어 조사 자동 선택 | `euro()` — "고지서**로**" / "안내문**으로**" |
| 음성 읽기 | 브라우저 TTS |
| 비식별 이벤트 로그 | 스키마가 자유 텍스트 필드를 허용하지 않음 |
| 서버 하드닝 | 근거 없는 날짜·금액·연락처·납부수단 제거 |
| 관리자 화면 차단 | `ADMIN_CODE` — `/admin`, `GET /api/logs`, `/api/status` |
| 분석 요청 속도 제한 | 주소당 분당 N회 (인스턴스별 메모리) |

## 🎬 시연을 위해 흉내 낸 것

| 항목 | 실제로는 |
|---|---|
| 분석 진행률 4단계 | 고정 시간 애니메이션. 실제 진행률이 아님 |
| 복습 알림 | localStorage. 푸시 알림 아님. 브라우저를 지우면 사라짐 |
| "저녁이 되었다고 치기" 버튼 | 시간을 앞당기는 시연용 버튼. 화면에 그렇게 적혀 있음 |
| 예시 문서 분석 결과 | 미리 검증한 결과. 모델을 그때 부르지 않음 |
| 결제앱 화면 | 실제 앱이 아니라 직접 그린 합성 화면 (`○○ペイ`) |

## ❌ 없는 기능

- 기기 내 개인정보 마스킹 (복습 화면 텍스트 마스킹만 있음)
- 실제 결제·송금·납부·신청 제출
- 법률 판단, 의료 진단
- 파인튜닝 / 학습 (프롬프트와 스키마만 사용)
- 적응형 힌트 (힌트는 항상 고정 3단계)
- 인지능력 점수, 사용자 등급
- PaddleOCR / Hybrid 제공자
- 진짜 인증 (`ADMIN_CODE` 는 가림막이지 인증이 아님)

## 표현 규칙

효과가 측정되지 않았습니다. **"AI 의존도를 줄이는 것을 목표로 설계했다"**
라고 말하고, **"줄였다"** 고 말하지 마세요. `Independent Completion Rate` 와
`Hint Reduction` 은 합성 연습본에서 측정한 설계 목표치이지, 실제 의존도가
낮아졌다는 증거가 아닙니다.

`docs/MODEL_COMPARISON.md` 는 아직 **빈 양식**입니다. 채우기 전에는 모델 비교
수치를 인용하지 마세요.

## 합성문서 표시

예시 문서에서 상단 배지는 없앴지만, **문서 그림 자체에 "합성문서입니다"가
인쇄되어 있습니다**. 이 문구가 없는 예시 문서가 생기면 테스트가 실패합니다
(`tests/privacy.test.ts`). 표시는 화면 장식이 아니라 문서에 붙어 있습니다.
