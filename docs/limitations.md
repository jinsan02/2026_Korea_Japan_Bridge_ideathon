# AI Door 한계와 미검증 범위

이 문서는 구현된 기능, 기대 효과, 검증된 결과를 섞지 않기 위한 공개 한계 문서다.

## 구현과 기대 효과

| 구현된 기능 | 기대 효과 | 현재 증거 |
|---|---|---|
| 근거 ID가 없는 날짜·금액·연락처를 제거하는 서버 하드닝 | 모델의 단정적 오류가 사용자 행동으로 이어질 위험 완화 | 단위 테스트로 로직 검증. 실제 문서 안전성·오류율은 미측정 |
| 선택지 3개와 6단계 해결 흐름 | 고령 사용자의 다음 행동 선택 부담 완화 | fixture 흐름 테스트. 실제 사용자 과업 연구 없음 |
| 매뉴얼·유사 합성문서·3단계 힌트·도움 감소 상태 | 같은 문서를 다음에 스스로 처리하도록 지원 | 상태 전이 테스트. AI 의존도 감소 효과는 미측정 |
| 한국어·일본어 UI와 fixture 콘텐츠 | 한일 시연과 다국어 접근 지원 | 타입·fixture 회귀 테스트. 번역 정확도·원어민 자연스러움 미검증 |
| 비식별 이벤트 스키마와 복습 텍스트 마스킹 | 로그로 문서 원문이 유입될 가능성 축소 | 스키마·패턴 테스트. 온디바이스 이미지 마스킹은 미구현 |
| `ADMIN_CODE`와 요청 속도 제한 | 공개 데모의 우발적 접근·비용 폭주 완화 | 코드와 로컬 경로 검증. 운영 인증·분산 공격 방어 아님 |

## 정확도와 사용자 연구

- 실제 한국·일본 행정문서 사진으로 OCR/구조화 정확도를 측정하지 않았다.
- 날짜, 금액, 연락처, 문서 유형별 precision/recall 또는 오류율이 없다.
- 노인 참가자를 대상으로 사용성, 이해도, 과업 성공률, 인지부하를 측정하지 않았다.
- “AI 의존도를 줄였다”, “문서 이해도가 향상됐다”는 성과 표현을 사용할 근거가 없다.
- A/B/C 이벤트 구조는 구현됐지만 실제 사용자 실험 결과가 아니다.

## 언어와 번역

- 일본어 UI·fixture 문안은 일본어 원어민 감수 기록이 없다.
- 언어 전환 경로와 번역 누락 회귀는 테스트하지만, 의미 보존·경어·행정용어 정확도를 보장하지 않는다.
- 라이브 문서는 클라이언트 번역이 아니라 제공자 재분석을 사용하므로 모델에 따라 표현이 달라질 수 있다.

## 보안과 운영

- `OPENAI_API_KEY`는 서버 전용이며 Git 또는 `NEXT_PUBLIC_*` 번들에 포함되지 않는다.
- 공개 `/api/analyze`는 사용자 인증이 없으므로 키 자체가 보이지 않아도 제3자가 API 비용을 발생시킬 수 있다.
- 속도 제한은 인스턴스별 메모리이고 `x-forwarded-for`에 의존한다. 공유 쿼터·WAF·분산 공격 방어가 아니다.
- `ADMIN_CODE`는 공유 비밀을 쿠키에 그대로 저장하는 데모용 가림막이다. 계정, 권한, 감사 로그,
  코드 회전·폐기, 중앙 세션 무효화가 있는 운영 인증이 아니다.
- 이벤트 로그는 서버리스 인스턴스별 파일/메모리 상태라 영속성·일관성·완전성이 없다.
- 운영 비밀 관리, 침투 테스트, 의존성 취약점 조치, 장애 모니터링과 복구 훈련 기록이 없다.

## 검증 환경의 한계

- 자동 테스트는 Node 환경의 단위·통합 테스트이며 실제 브라우저 E2E가 아니다.
- 실제 휴대폰 카메라 업로드, 브라우저 TTS, 화면 낭독기 사용성은 기기별로 검증되지 않았다.
- 저장소에는 배포 URL의 최소 OpenAI 호출 기록이 있지만 실제 문서 정확도 검증은 아니다.
- Ollama 경로와 Qwen3-VL의 실제 품질·지연은 현재 검증되지 않았다.
- 배포 플랫폼 정책, 모델 동작, 외부 API는 이후 변경될 수 있다.

## 안전한 포트폴리오 표현

사용 가능:

> 근거 없는 날짜·금액·연락처를 제거하는 서버 하드닝과 사람 확인 전환을 구현하고,
> 80개 자동 테스트·strict 타입 검사·프로덕션 빌드로 코드 불변조건을 검증했다.

사용하면 안 됨:

> 행정문서 인식 정확도를 입증했다 / 일본어 번역을 검증했다 / 고령자의 AI 의존도를 낮췄다 /
> 운영 수준 인증과 보안을 완성했다.
