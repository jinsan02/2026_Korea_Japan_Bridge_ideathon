# 시연 가이드

## 시연 전 점검 (2분)

```bash
npm run build && npm start
```

- [ ] 홈 상단에 `가` 버튼, `🌐 日` 버튼, AI DOOR 로고가 한 줄에 보이는지
- [ ] `가` 를 세 번 누르면 커졌다가 처음 크기로 돌아오는지
- [ ] `/admin?key=<코드>` 로 들어가 `학습 기록 초기화` (도움 수준을 처음으로)
- [ ] 발표용 브라우저에서 `/admin` 탭을 **닫아 둘 것**
- [ ] 기기 화면 자동 꺼짐 끄기

## 두 트랙 — 섞지 마세요

| | 트랙 1 (한국) | 트랙 2 (일본) |
|---|---|---|
| 이 사람은 | 한국 고령자 | 일본 고령자 |
| 받은 것 | 지방세 납세고지서 | 가스요금 払込票 |
| 진짜 어려운 것 | 날짜가 두 개, 금액이 두 개 | 바코드를 찍었더니 나온 앱 화면 |

**말하면 안 되는 것:** "일본 어르신께 8,181엔이 낼 금액이라고 알려 줍니다."
일본 어르신은 엔화를 압니다. 그렇게 말하면 그 자리에서 설득력을 잃습니다.

**말할 것:** "앱에 뜬 잔액은 통장 돈이 아니라 미리 넣어 둔 돈입니다. 그걸
모르면 예약해 두고도 결제가 실패합니다."

## 90초 시연 순서

### 트랙 1 — 한국 지방세 (40초)

1. 홈 → `지금 같이 해결하기`
2. `지방세 납세고지서 (한국)` 선택 → `이 문서로 확인하기` → `이해했습니다`
3. **여기서 멈추고 화면을 가리킬 것.** 네/아니요가 아니라 선택지 3개가 뜹니다.
   > "무엇부터 도와드릴까요 — 납부 메뉴 찾기, 어디에 적혀 있는지 보기,
   > 순서대로 같이 확인하기."
4. `납부 메뉴 찾기` → 6가지가 나오고, 각각 **무엇이 필요한지**가 적혀 있음
   > "은행 창구는 고지서만 들고 가면 됩니다. ATM은 카드와 납부번호가 필요합니다.
   > 이 6가지는 전부 고지서에 적혀 있는 것만입니다."
5. 아래로 스크롤 → `확인이 필요한 부분`
   > "늦게 냈을 때 낼 금액은 고지서에 없습니다. AI가 계산해서 채우지 않습니다."

### 트랙 2 — 일본 가스요금 → 앱 화면 (40초)

6. 뒤로 → `가스요금 납부용지 (일본)` 선택 → 진행
7. `순서대로 같이 확인하기` → 6단계 중 2~3단계만 보여주고 완료
8. 완료 화면의 **파란 카드**를 가리킬 것
   > "바코드를 찍으면 화면이 하나 더 나옵니다. 그 화면도 문서입니다."
9. `앱 화면 사진 보여주기` → 선택지가 바뀜:
   `버튼 위치 안내받기` / `얼마를 언제까지인지 보기` / `결제 순서 확인하기`
10. `버튼 위치 안내받기` → `원문 위치 보기` → 앱 화면의 버튼에 하이라이트
    > "「지금 내기」는 누르는 순간 나갑니다. 「예약」은 아직 낸 게 아닙니다.
    > 이 차이를 모르면 예약해 놓고 다 냈다고 생각합니다."

### 마무리 (10초)

11. 상단 `🌐 日` 누르기 → `이 언어로 다시 읽기`
    > "같은 화면을 일본어로 다시 읽습니다."

## 질문이 나오면 여는 화면

| 질문 | 화면 |
|---|---|
| "AI가 지어내면요?" | `/evidence` — 모든 판단에 원문 인용이 붙음 |
| "의존만 커지는 것 아닌가요?" | `/practice` — AI가 답을 먼저 주지 않고 힌트 3단계 |
| "다음에 또 받으면요?" | `/tutorial` — 확인 순서만 남고 금액·이름은 없음 |
| "개인정보는요?" | `/admin` → CSV 내려받기 → 문서 본문이 한 줄도 없음 |
| "특허 문제는요?" | 힌트는 항상 고정 3단계입니다. 사용자별로 난이도를 바꾸는 적응형 모델을 쓰지 않습니다 |

## 실패했을 때

| 증상 | 대응 |
|---|---|
| 분석이 멈춤 | `분석 취소` → 다시. 12초 뒤 자동으로 선택지가 뜸 |
| 온라인 모드 실패 | 화면이 이유를 말하고 예시 문서로 갈지 물어봄. 그대로 진행 |
| 화면이 깨짐 | 상단 `가` 를 눌러 글자 크기를 보통으로 되돌림 |
| 진행이 꼬임 | `/` 로 가서 처음부터. 세션은 새로고침에도 살아 있음 |

## 하지 말아야 할 말

- ❌ "AI 의존도를 줄였습니다" → ⭕ "줄이는 것을 목표로 설계했습니다"
- ❌ "실시간 AI 분석입니다" (예시 문서를 쓰는 동안) → ⭕ "미리 검증한 결과입니다"
- ❌ "일본 어르신께 금액을 알려 줍니다" → ⭕ "앱 화면의 개념을 설명합니다"
- ❌ "○○페이 연동" → ⭕ "직접 만든 합성 화면입니다"
