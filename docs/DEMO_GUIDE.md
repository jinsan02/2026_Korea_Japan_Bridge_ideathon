# 발표 시연 가이드

## 0. 시연 전 체크리스트 (발표 30분 전)

- [ ] `npm run build && npm start` 로 프로덕션 모드 실행 (dev보다 빠르고 안정적)
- [ ] 브라우저를 **모바일 폭**으로 (개발자도구 375×812 또는 실제 스마트폰)
- [ ] `/lab` 에서 모드 확인
  - 인터넷 확실할 때: `온라인 기본 모드`
  - 불확실할 때: **`안전 시연 모드 — Fixture`** ← 권장
- [ ] `/lab` → `학습 기록 초기화` (도움 수준을 `따라 하기`로 되돌림)
- [ ] `/history` 가 비어 있는지 확인
- [ ] 글자 크기 `크게` 로 설정 (화면 뒤쪽 관객용)
- [ ] 소리 확인 — 음성 읽기를 한 번 눌러봄
- [ ] 종이 합성 고지서 1장 + 봉투 준비 (실사 도입 촬영용)
- [ ] 비상용 스크린샷 6장 준비

## 2. Q&A용 클릭 시연 (실시간)

**반드시 보여줄 세 화면** (이게 없으면 일반 OCR 앱과 차이가 약해집니다):

1. **행동카드 3개** — `/result`
2. **원문 근거 위치** — `/evidence` 또는 `/solve`의 `원문에서 보여주세요`
3. **복습 + 3단계 힌트** — `/practice`

추가로 보여주면 좋은 것:

- `/capture` → **복지 안내문** 선택 → `/result`
  → **금액 칸이 "문서에 적혀 있지 않습니다"** 로 나옴.
  "적혀 있지 않은 것을 AI가 만들어내지 않는다"를 보여주는 가장 강한 장면입니다.
- `/lab` → 모드 4개와 Ollama 연결 상태
- `/lab` → CSV 내려받기 → 개인정보가 없다는 것 확인

## 3. 오류 대응 시나리오

| 상황 | 화면에 나오는 것 | 발표자가 할 일 |
|---|---|---|
| 인터넷 끊김 | `AI 서버에 연결하지 못해 데모 모드로 보여드립니다` | 그대로 진행. "네트워크가 끊겨도 발표가 멈추지 않도록 설계했습니다" |
| API 키 없음 | `API 키가 없어서 데모 모드로 보여드립니다` | 동일 |
| 분석 실패 | `지금은 온라인 분석이 원활하지 않습니다. 안전한 예시 문서로 계속 체험하시겠어요?` | `예시 문서로 계속하기` 클릭 |
| 응답이 12초 넘게 지연 | `조금 오래 걸리고 있습니다` + `예시 결과 보기` | `예시 결과 보기` 클릭 |
| Ollama 미실행 | `/lab`에 `연결되지 않음` | `/lab`에서 `안전 시연 모드`로 전환 |
| 화면이 완전히 멈춤 | — | 브라우저 새로고침 → `/lab` → Fixture → 다시 시작 |
| 노트북 자체가 죽음 | — | 사전 녹화 영상 재생 → 그것도 실패하면 스크린샷 6장 |

**원칙: 데모 모드로 넘어가도 숨기지 마세요.** 화면에 이유가 표시되므로,
"실패해도 발표가 계속되도록 만든 안전장치입니다"라고 그대로 설명하는 편이 더 강합니다.

## 4. 영상 촬영 준비물

- 개인정보 없는 합성 지방세 고지서 1장 (README §6의 값으로 인쇄)
- 구청 봉투처럼 보이는 일반 봉투
- 스마트폰 1대, 식탁 또는 책상
- 손만 등장하는 촬영자 1명
- 내레이션 음성, 한국어·영어 자막
- 영상 재생 실패 대비 스크린샷 6장

## 5. 발표자가 영상 전후에 할 말

**영상 전**

> 이제 AI Door가 한국의 한 시니어에게 실제로 어떻게 쓰이는지 보여드리겠습니다.
> 사용자는 AI에게 무엇을 물어야 하는지 알 필요가 없습니다. 받은 문서를 보여주기만 하면 됩니다.

**영상 후**

> 이 시연의 핵심은 문서 요약이 아닙니다.
> 기존 AI는 사용자의 문제를 대신 해결합니다.
> AI Door는 처음에는 함께 해결하지만, 그 경험을 매뉴얼과 연습으로 바꾸어
> 다음에는 사용자가 스스로 해결하도록 돕습니다.

**특허·유사서비스 질문이 나오면** (`06_PRIOR_ART` 근거)

> OCR, 문서요약, 적응형 힌트 각각에는 선행기술이 존재합니다.
> 저희는 기술 조각 자체를 독점적이라고 주장하지 않습니다.
> 차별점은 원문 근거가 연결된 행동카드와, 해결 후 도움을 줄여가는 공문서 자립 루프입니다.
> 상용화 단계에서는 한·일 청구항을 대상으로 별도 FTO 검토를 진행할 계획입니다.
