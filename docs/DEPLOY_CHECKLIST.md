# 배포 점검표

공개 URL로 시연하기 전에 확인할 것. 아래 항목은 전부 **실제로 확인한 것**이며,
"확인 못 함"으로 남은 것은 그렇게 적어 두었습니다.

## 1. 환경변수 (배포 플랫폼에 등록)

```bash
AI_PROVIDER=openai            # 또는 fixture
OPENAI_API_KEY=...            # AI_PROVIDER=openai 일 때만
ADMIN_CODE=충분히_긴_문자열     # 비우면 production 에서 관리자 화면이 막힙니다
ANALYZE_RATE_LIMIT_PER_MINUTE=10
```

**넣지 말 것:** `OLLAMA_*` (클라우드에서 로컬 모델은 돌지 않습니다),
`ALLOW_CLIENT_PROVIDER_OVERRIDE=true` (방문자가 OpenAI 모드를 강제로 켜서
키를 쓰게 할 수 있습니다 — production 기본값은 `false` 입니다).

## 2. 배포 직후 확인 (curl 5줄)

```bash
D=https://<도메인>
curl -s -o /dev/null -w "home   %{http_code}\n" $D/
curl -s -o /dev/null -w "status %{http_code}\n" $D/api/status      # 404 여야 정상
curl -s -o /dev/null -w "logs   %{http_code}\n" $D/api/logs        # 404 여야 정상
curl -s $D/admin | grep -c "분석 모드"                               # 0 이어야 정상
curl -s -c /tmp/c -o /dev/null "$D/admin?key=<ADMIN_CODE>" && curl -s -b /tmp/c $D/admin | grep -c "분석 모드"   # 1 이어야 정상
```

로컬 production 빌드에서 위 다섯 줄이 `200 / 404 / 404 / 0 / 1` 로 나오는 것을
확인했습니다.

## 3. 미리 잡아 둔 함정

| 위험 | 어떻게 됐었나 | 지금 |
|---|---|---|
| **예시 문서 클릭이 전부 실패** | `AI_PROVIDER=openai` + 클라이언트 오버라이드 off 면, 예시 문서(이미지 없음)가 OpenAI 경로로 가서 `unsupported_type` 으로 실패. 시연마다 실패 화면이 먼저 뜸 | `fixtureId` 가 있고 이미지가 없으면 무조건 fixture 로 처리 |
| **업로드 413** | `MAX_UPLOAD_BYTES=6000000` → base64 로 약 8MB 전송. 서버리스 본문 상한(대개 4.5MB)에 걸려 **우리 코드가 실행되기도 전에** 플랫폼이 거절 | 3MB 로 낮춤. 클라이언트가 1600px 로 줄이므로 실제 사진은 1MB 안쪽 |
| **분석 도중 함수 강제 종료** | 비전 모델은 20~40초가 보통인데 서버리스 기본 타임아웃이 훨씬 짧음 | `maxDuration = 60` 선언. **긴 함수를 허용하는 요금제가 필요합니다** — 안 되면 예시 문서 모드로 시연 |
| **아이폰에서 사진 업로드 실패** | Safari 는 `createImageBitmap` 은 있지만 `imageOrientation` 옵션을 거부(reject)하던 시기가 있음. 그대로 실패로 전파됐음 | 실패하면 `<img>` 경로로 폴백 |
| **강제 다크 모드에서 화면이 깨짐** | 앱은 라이트 전용인데 `color-scheme` 선언이 없어 일부 브라우저가 폼 컨트롤만 반전 | `color-scheme: light` 선언 |
| **예시 문서 기한이 지나 있음** | 일본 용지가 `기한이 119일 지났습니다` 로 표시됨 | 날짜를 옮겼고, **기한이 지나면 테스트가 실패**합니다 |

## 4. 알고 넘어가는 제약

- **`ADMIN_CODE` 는 인증이 아니라 가림막입니다.** 코드를 아는 사람은 전부
  볼 수 있습니다. 뒤에 있는 건 이벤트 로그뿐이고, 스키마가 개인정보를 애초에
  거부합니다.
- **속도 제한은 인스턴스별 메모리 기준입니다.** 서버리스는 인스턴스가 여러 개
  뜨므로 실제 상한은 설정값보다 느슨합니다. 반복 호출로 인한 비용 폭주를 막을 뿐,
  분산 공격은 못 막습니다.
- **이벤트 로그 파일은 클라우드에서 안 남습니다.** 파일 쓰기가 실패하면 조용히
  메모리에만 유지되고, 인스턴스마다 따로입니다. CSV 를 받으면 그 인스턴스가 본
  것만 나옵니다.
- **Ollama 는 클라우드에서 안 됩니다.** 관리자 화면에 `연결되지 않음` 으로
  표시됩니다. 로컬 시연 전용입니다.
- **폰트**: 합성문서는 `Malgun Gothic → Noto Sans KR/JP → sans-serif` 순서라
  iOS 에서는 시스템 폰트로 떨어집니다. 글자는 정상적으로 보이지만 윈도우와
  글꼴이 다릅니다.

## 5. 확인하지 못한 것

- **실제 OpenAI 호출.** 이 환경에 키가 없어 코드 경로만 완성돼 있습니다.
  `gpt-5.6-luna` / `gpt-5.6-terra` 가 계정에서 실제로 쓸 수 있는 모델인지
  **배포 전에 한 번은 실제로 눌러 봐야 합니다.** 안 되면 `.env` 의 모델명만
  바꾸면 됩니다.
- **실제 휴대폰에서의 카메라 업로드.** `capture="environment"` 는 HTTPS 에서만
  동작합니다. 배포 URL 은 HTTPS 이므로 조건은 맞지만, 기기에서 직접 확인하지는
  못했습니다.
- **음성 읽기(TTS).** 브라우저·기기마다 한국어/일본어 음성 설치 여부가 다릅니다.

## 6. 시연 당일 순서

1. 배포 URL 을 폰에서 열고 `가` 버튼을 세 번 눌러 글자 크기가 순환하는지 확인
2. 예시 문서 두 개를 각각 끝까지 한 번씩 돌려 보기
3. `/admin?key=...` 로 들어가 `학습 기록 초기화` (도움 수준을 처음으로)
4. **관리자 탭을 닫을 것**
5. 기내 모드로 바꿔서 한 번 더 — 예시 문서 모드가 네트워크 없이 도는지 확인
